# EdgeShelf 边缘收纳

![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078d4)
![Runtime](https://img.shields.io/badge/.NET-8.0-512BD4)
![UI](https://img.shields.io/badge/UI-WPF-512BD4)
![Version](https://img.shields.io/badge/version-beta1.11.1-4c8dff)
![License](https://img.shields.io/badge/license-MIT-green)

> 屏幕边缘一条窄窄的蓝色标签，鼠标移过去滑出一块收纳面板——把文件夹、快捷方式、常用文件统统收进边缘，桌面始终保持干净。

**EdgeShelf** 是一款 Windows 10 / 11 的**桌面边缘收纳工具**，灵感来自旧版 QQ 侧边条：它不替换你的桌面，不动壁纸、不接管桌面图标，只在屏幕边缘停靠一条约 10px 的蓝色标签，鼠标靠近即自动滑出收纳面板。面板里是一个个「抽屉」——每个抽屉对应磁盘上的一个文件夹，展开即可看到里面的子文件夹、快捷方式和文件图标，点击直接打开。

- ✅ **不碰桌面**：桌面图标、壁纸、桌面右键菜单全部原样保留
- ✅ **原生轻量**：C# / WPF 原生实现，单进程常驻托盘；内置.NET 8版内存占用实测约 100–150 MB（.NET 8 运行时 + WPF 的正常水平，与抽屉数量关系不大）；介意内存可用无内置版`EdgeShelf-net8.exe`（与系统共享 .NET 运行时），占用约40MB左右
- ✅ **收纳即引用**：只「显示」磁盘上的文件夹，不复制、不移动、不删除你的任何文件
- ✅ **多侧边栏 / 页签 / 多显示器**：一条不够就加一条，还能合并页签共用面板

## 📖 功能介绍

### 一、收纳与整理

- **抽屉分组**：面板就是一组「抽屉」，每个抽屉对应磁盘上的一个文件夹。点击抽屉名字行展开 / 收起，展开后显示其中的子文件夹、快捷方式和文件，点击直接打开。
- **内部分组（钻入）**：抽屉里点击子文件夹可以钻进去继续分类；右上角「返回上级」按钮或再点一次名字行可返回抽屉根目录。
- **收文件夹**：三种方式——双击面板空白处、点面板头部 ＋ 按钮（支持多选）、或直接把文件夹从资源管理器拖进面板。
- **收快捷方式**：点头部链接图标，或直接把 `.lnk` 拖进面板。首次使用会先让你选一个「快捷方式存放文件夹」，之后软件自动把快捷方式复制进去并建立抽屉。这样卸载软件时快捷方式留在你的文件夹里，不会丢。
- **搜索**：面板头部搜索框按名称过滤所有抽屉里的内容，自动展开命中的抽屉，`Esc` 一键清空。

### 二、展示与排序

- **宫格视图（默认）**：图标瓦片排布，适合快速浏览；按住图标拖动即可手动排序，顺序自动保存。
- **列表视图**：头像 + 名称竖排，信息密度更高；头部按钮一键切换，**每个页签各自记忆**视图模式。
  - 列表模式下点击**文件夹**是**内联展开**（递归显示其子项，缩进树形），不改变当前路径，也不影响抽屉的钻入状态；
  - 列表模式下按住**顶层行**拖动同样可以排序，子行按树结构归属、不参与排序。
- **抽屉排序**：右键抽屉 → 上移 / 下移 / 上移置顶 / 下移置底，顺序随配置持久化。

### 三、文件操作（右键菜单）

对抽屉里的**文件和文件夹一视同仁**，右键图标即可：

| 操作 | 说明 |
| --- | --- |
| 打开位置 | 在资源管理器中打开文件 / 文件夹所在目录 |
| 重命名… | 直接修改磁盘上的文件名；快捷方式会自动保留 `.lnk` / `.url` 扩展名 |
| 移动到其他抽屉… | 跨抽屉移动（可跨侧边栏），同名自动加「(2)」序号，不会覆盖 |
| 删除（移入回收站） | 文件或文件夹整树移入回收站，可随时还原，不真正抹掉数据 |

抽屉（分组）本身的右键菜单：打开位置、在此新建子文件夹、重命名分组、上移 / 下移 / 置顶 / 置底、删除分组（删除只会移除配置引用，不动磁盘文件）。

### 四、停靠与交互

- **边缘停靠**：可停靠屏幕左 / 右 / 顶 / 底四条边；设置里也可以选择 **L 形拐角**（左上 / 右上 / 左下 / 右下）。
- **拖动定位**：按住蓝色窄条沿边拖动可移动位置；拖到另一条屏幕边缘自动换边，经过屏幕角时先变 L 形过渡再落边。
- **点击开合**：点击窄条展开 / 收起面板。
- **边缘触发**：鼠标移到窄条所在位置（默认窄条范围，可设置整条边缘都触发）停留 140ms 自动滑出；移开后 380ms 缓冲再收起。
- **固定面板**：面板头部 ▼ 按钮把面板钉住不自动收回（固定 ⇄ 正常绑定，固定时蓝条始终可见可触碰）。
- **手动调整大小**：面板右边有宽度把手、上下两端有高度把手，实时拖拽改宽高（双向可拉）；设置里也能用滑块 + 数字精确输入。
- **多显示器**：每个侧边栏可「跟随鼠标所在屏幕」或固定在某块屏幕上，DPI 缩放自动适配。

### 五、外观与模式

- **窗口主题**：设置里可选——**无主题**（自定义配色）/ **云母 Mica**（Win11 22H2+ 系统效果）/ **Aero**（亚克力毛玻璃，失败自动回退半透明模糊）/ **WinXP Luna** / **Win98 Classic** / **Metro**（后三个为内置配色方案）。
- **双色定制**：窄条主题色与面板主题色可**独立选择**，11 种预设色（含灰 / 黑 / 白）。
- **白天 / 黑夜**：一键切换浅色面板 + 深色文字 / 深色面板 + 浅色文字。
- **透明度**：面板透明度 0–100% 可调，0% 即全透明幽灵面板。
- **三种模式**（设置里可切换，托盘也可随时切换）：
  - **普（正常）**：蓝条可见、可拖动，边缘接近触发；
  - **透（透明）**：蓝条隐形且鼠标掠过不触碰，边缘接近仍触发——适合想保留触发、又不想看到条；
  - **无（无痕）**：蓝条隐形、边缘触发完全关闭，只能靠托盘菜单或全局快捷键唤回，适合摸鱼。
- **全局快捷键**：设置里自定义（如 Ctrl+Alt+E），**按序循环切换已勾选的模式**（普→透→无→固，勾选项可自定义）。
- **点击穿透**：透明 / 无痕模式下，面板透明区域不拦截点击，不会挡住窗口的最小化 / 最大化 / 关闭按钮。

### 六、多侧边栏与页签

- **多侧边栏**：每个侧边栏是独立的配置（停靠位置、尺寸、外观、分组互不影响），托盘里可分别操作。
- **页签合并**：右键页签「合并此页签到…」或右键蓝色栏「合并此侧边栏到…」，多个侧边栏共用一个面板，顶部页签切换，分组各自保留。
- **分离**：右键合并进来的页签「从此侧边栏分离」，恢复成独立侧边栏。
- **新建 / 删除**：页签栏右侧 ＋ 新建页签；托盘 / 设置里新建侧边栏时可选择**独立建立**或**作为页签加入现有侧边栏**；右键可删除（有确认提示）。

### 七、系统集成

- **系统托盘**：每个侧边栏一个子菜单——展开 / 收起面板、切换模式（正常 / 透明 / 无痕 / 固定）、设置、删除；另有新建侧边栏、开机自启、退出。
- **开机自启**：托盘勾选后写入 HKCU 注册表 Run 项 + 启动文件夹快捷方式 + 任务计划程序**三重保险**，每次启动自动用当前 exe 路径自愈，防止路径变更失效。
- **实时刷新**：抽屉文件夹内容变化（增删改文件）自动刷新，无需手动重新加载。
- **单实例**：重复启动只会唤起已有实例，不会开两份。
- **配置迁移**：旧版本配置启动时自动迁移，升级不丢分组、位置和外观设置。

## 🚀 快速上手

1. **运行**：双击 `EdgeShelf.exe`，屏幕左边缘出现一条蓝色窄条。
2. **滑出面板**：鼠标移到屏幕左边缘的蓝条上，面板自动滑出。
3. **收一个文件夹**：把文件夹直接拖进面板，或双击面板空白处选择。
4. **收快捷方式**：点头部链接图标，选一个存放文件夹（如 `D:\工具\edgeshelf`），以后所有快捷方式都收进去。
5. **整理**：点抽屉名字展开，按住图标拖动排序，右键图标重命名 / 移动 / 删除。
6. **调外观**：点头部设置 ⚙，改停靠边、尺寸、主题色、透明度、模式，勾选开机自启。
7. **多开一条**：托盘菜单「新建侧边栏」，或页签栏右侧 ＋ 再开一个页签。

常用操作速查：

| 操作 | 方法 |
| --- | --- |
| 展开 / 收起面板 | 点击蓝色窄条；鼠标移到边缘窄条区域自动滑出 |
| 固定面板 | 面板头部 ▼ 按钮（或托盘菜单） |
| 切换宫格 / 列表 | 面板头部列表图标按钮 |
| 添加抽屉 | 双击面板空白处 / 头部 ＋ / 把文件夹拖进面板 |
| 添加快捷方式 | 头部链接图标 / 把 `.lnk` 拖进面板 |
| 折叠 / 钻入抽屉 | 点名字行展开收起；点子文件夹钻入，名字行返回 |
| 调整面板大小 | 拖动面板侧边（宽度）与上下两端（高度）的亮色把手 |
| 移动位置 / 换边 | 按住蓝色窄条拖动；拖到其他屏幕边缘自动换边 |
| 合并侧边栏 | 右键页签「合并此页签到…」或右键蓝色栏「合并此侧边栏到…」 |
| 分离页签 | 右键合并页签「从此侧边栏分离」 |
| 切换模式 | 设置里选 普 / 透 / 无；托盘菜单或全局快捷键 |
| 删除 | 右键页签 / 蓝色栏 → 删除（有确认提示，不动磁盘文件） |

## 🔧 从源码构建

要求：Windows 10 / 11 + [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
cd Release-EdgeShelf
.\build.ps1            # Debug 编译 → EdgeShelf\bin\Debug\net8.0-windows\EdgeShelf.exe
.\build.ps1 -Publish   # 发布自包含单文件 exe（需联网下载 runtime pack）
.\build.ps1 -Clean     # 先清理 bin/obj
```

> 构建脚本会把 NuGet 缓存重定向到工作区 `running\.nuget` / `running\.dotnet`，方便离线 / 受限环境。应用图标资源为 `EdgeShelf\App.ico`（源自仓库根目录的 `Shelf E black.ico`）。

## ❓ 常见问题

**它和桌面整理类软件有什么区别？**
EdgeShelf 不替换桌面——桌面图标和壁纸原样保留，它只是一个常驻屏幕边缘的收纳面板，喜欢旧版 QQ 侧边条交互的人会觉得很顺手。

**卸载软件后快捷方式会消失吗？**
不会。快捷方式是复制到你自己选择的文件夹里的，软件只是显示它们；卸载或删除抽屉都不会动磁盘上的文件。

**为什么我的旧配置没丢？**
启动时会自动把旧版单侧边栏配置迁移到新版 `Sidebars` 列表格式，升级无感。

**开机自启怎么设置？**
托盘菜单勾选「开机自启」。采用**三重保险**：HKCU 注册表 Run 项 + 启动文件夹快捷方式 + 任务计划程序（登录触发），每次启动自动用当前 exe 路径自愈（刷新三项）。单实例互斥保证即便三重同时触发也只会开一份。

**透明 / 无痕模式下蓝条不见了，怎么打开面板？**
- 透明模式：鼠标移到屏幕边缘蓝条原来的位置仍会触发；
- 无痕模式：触发已关闭，用托盘菜单「展开 / 收起面板」或全局快捷键唤回。

**为什么没看到桌面图标变化？**
EdgeShelf 本来就不接管桌面，你的桌面什么样还是什么样。

**找不到托盘图标？**
EdgeShelf 托盘图标是黑色调（Shelf E black），在任务栏右下角向上箭头（隐藏图标）里，可以把它拖到可见区。
