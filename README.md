# EdgeShelf 边缘收纳

![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078d4)
![Runtime](https://img.shields.io/badge/.NET-8.0-512BD4)
![UI](https://img.shields.io/badge/UI-WPF-512BD4)
![Version](https://img.shields.io/badge/version-1.4.1-4c8dff)
![License](https://img.shields.io/badge/license-MIT-green)

> 像旧版 QQ 侧边条一样的桌面「边缘收纳栏」——不替换桌面，屏幕边缘一条蓝色窄条，鼠标移过去滑出面板，把文件夹和快捷方式收纳整齐。

EdgeShelf 是一个 **Windows 10/11 桌面边缘收纳工具**，类似 Fences / Nimi Places，但**不会替换你的桌面**：
桌面图标、壁纸原样保留，平时屏幕上只有边缘一条窄窄的蓝色标签，鼠标移到边缘自动滑出面板，里面是多个「抽屉」（文件夹分组）的快捷方式 / 文件图标。

- ✅ 不碰桌面，不换壁纸，不接管桌面图标
- ✅ 原生 C# / WPF，单进程常驻托盘，内存占用约 20–40 MB
- ✅ 支持多侧边栏、页签合并、L 形拐角、多显示器

## ✨ 功能特性

### 收纳
- **抽屉分组**：面板就是一组「抽屉」（文件夹分组），每张抽屉一行名字，点击展开 / 收起；展开后显示子文件夹 / 快捷方式 / 文件图标，点击直接打开
- **内部分组**：抽屉里点击子文件夹可钻入继续分类，右键抽屉可「在此新建子文件夹」
- **收文件夹**：双击面板空白处、点头部 ＋、或直接把文件夹拖进面板
- **收快捷方式**：点头部链接图标（或把 `.lnk` 拖进面板）→ 选择自己的快捷方式文件夹，软件自动复制并建抽屉——**卸载软件后快捷方式仍在**

### 停靠与外观
- **边缘 / 拐角**：可停靠左 / 右 / 顶 / 底，或选 **L 形拐角**（四个角）
- **拖动定位**：按住蓝色窄条拖动沿边移动位置；拖到另一条边自动换边；设置里可精确调整或一键居中
- **点击开合**：点击窄条展开 / 收起；鼠标移到窄条的实际位置自动滑出
- **固定面板**：头部 ▼ 按钮固定不自动收回
- **手动调整大小**：面板侧边 / 上下两端都有把手，实时拖拽改宽高；设置里也可滑块 + 数字输入
- **外观**：亚克力毛玻璃（Win10 1803+ / Win11，失败自动回退半透明）、透明度 0–100%（0% 即全透明幽灵面板）、8 种主题色

### 多侧边栏
- **页签合并**：右键页签「合并此页签到…」或右键蓝色栏「合并此侧边栏到…」，多个侧边栏共用一个面板，顶部页签切换，各自分组独立保留
- **分离**：右键合并页签「从此侧边栏分离」，恢复成独立侧边栏
- **多显示器**：每个侧边栏可跟随鼠标所在屏幕或固定在某块屏幕

### 其他
- **实时刷新**：抽屉文件夹内容变化自动刷新
- **托盘**：按侧边栏展开 / 收起 / 设置 / 删除、新建页签、开机自启、退出
- 数据保存在 `%APPDATA%\EdgeShelf\config.json`，旧版本配置自动迁移

| 方式 | 说明 |
| --- | --- |
| **`EdgeShelf.exe`** | 自包含单文件（约 63 MB），无需安装 .NET，双击即用 |

## 🚀 使用指南

| 操作 | 方法 |
| --- | --- |
| 展开 / 收起面板 | 点击蓝色窄条，或鼠标移到屏幕边缘窄条区域自动滑出 |
| 固定面板 | 面板头部 ▼ 按钮（或托盘菜单） |
| 添加抽屉 | 双击面板空白处 / 头部 ＋ / 把文件夹拖进面板 |
| 添加快捷方式 | 头部链接图标 / 把 `.lnk` 拖进面板（首次会先选存放文件夹） |
| 折叠 / 钻入抽屉 | 点击名字行展开收起；点击子文件夹钻入，再点名字行返回 |
| 调整面板大小 | 拖动面板侧边（宽度）与上下两端（高度）的亮色把手 |
| 移动位置 / 换边 | 按住蓝色窄条拖动；拖到其他屏幕边缘自动换边 |
| 合并侧边栏 | 右键页签「合并此页签到…」或右键蓝色栏「合并此侧边栏到…」 |
| 分离侧边栏 | 右键合并页签「从此侧边栏分离」 |
| 删除 | 右键页签 / 蓝色栏 → 删除（有确认提示，不动磁盘文件） |
| 新建页签 | 页签栏右侧 ＋，或托盘「新建侧边栏」 |

## 🔧 从源码构建

要求：Windows 10/11 + [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
cd Release-EdgeShelf
.\build.ps1            # Debug 编译 → EdgeShelf\bin\Debug\net8.0-windows\EdgeShelf.exe
.\build.ps1 -Publish   # 发布自包含单文件 exe（需联网下载 runtime pack）
.\build.ps1 -Clean     # 先清理 bin/obj
```

> 构建脚本会把 NuGet 缓存重定向到工作区 `running\.nuget` / `running\.dotnet`，方便离线 / 受限环境。

## 🗂️ 数据与配置

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\EdgeShelf\config.json` | 所有侧边栏的停靠位置、尺寸、外观、分组配置 |
| `%APPDATA%\EdgeShelf\error.log` | 运行错误日志（排障用） |

> 软件只引用磁盘上的文件夹，**不会移动或删除你的任何文件**；删除抽屉 / 页签只会移除配置引用。

## ❓ 常见问题

**和 Fences / Nimi Places 有什么区别？**
EdgeShelf 不替换桌面——桌面图标和壁纸原样保留，它只是一个常驻屏幕边缘的收纳面板，喜欢旧版 QQ 侧边条交互的人会觉得很顺手。

**卸载软件后快捷方式会消失吗？**
不会。快捷方式是复制到你自己选择的文件夹里的，软件只是显示它们；卸载或删除抽屉都不会动磁盘上的文件。

**为什么我的旧配置没丢？**
启动时会自动把旧版单侧边栏配置迁移到新版 `Sidebars` 列表格式。

**开机自启怎么设置？**
托盘菜单勾选「开机自启」（写入 HKCU 注册表 Run 项）。
